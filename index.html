System Map

The complete edge → cloud path. Inference never leaves the device until the keyword crosses threshold.

STAGE A · INPUT
INMP441Omni-directional MEMS mic · 24-bit I2S digital out · 16 kHz mono frames into the MCU.
STAGE B · EDGE INFERENCE
ESP32-S3VAD gate → MFCC features → INT8 DS-CNN → custom keyword “ORBIT”. All local, ~0 network bytes.
STAGE C · REMOTE ASR
Remote ASRFastAPI + open-source ASR over Wi-Fi. Pre-roll + live audio → transcript → command intent.
